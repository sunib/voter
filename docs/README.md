## Historical context

The [2026-09-10 handoff](../room-pass/state-2026-09-10.md) is a dated deployment
record with a review addendum. It is not a continuous live status report.

[Next steps](../next-steps.md) is an old session journal;
[Coffee App Minimum](../new-direction.md) describes product intent;
[talk outline](../talk-outline.md) and [frontend notes](../FRONTEND.md) preserve
the presentation and UI context. They do not define the current authentication model.

The older files under `plans/`, the authentication/impersonation proposals under
`docs/`, and `docs/alternatives/` explain earlier designs. References there to
`auth-service`, ForwardAuth, TokenRequest or browser-asserted identity are historical.
Follow the current architecture and implementation plan for new work. These
notes stay at their existing paths to preserve links and design history.
